#3 MD5 password hashing Critical
auth.py · hash_password()
Reproduce: Register an account, then login — observe the 32-char token returned. Both the stored password and the token are MD5 hashes, crackable offline in seconds. Fix by replacing with bcrypt. Assign yourself on GitHub →
#4 Hardcoded SECRET_KEY Critical
auth.py · line 4
Reproduce: Open src/auth.py — SECRET_KEY = "supersecret123" is in plain source. Anyone with repo access can forge tokens. Fix by reading from os.getenv("SECRET_KEY"). Assign yourself on GitHub →
#5 Bare except swallows errors Medium
auth.py · register_user()
Reproduce: Register the same username twice — no error is shown. The duplicate key violation is silently swallowed by a bare except: pass. Fix by catching sqlite3.IntegrityError specifically and returning a proper error. Assign yourself on GitHub →
